# free money holy shit 💸

A novelty Windows console program that doubles a pretend money counter every second. 💰 It does not generate real money.

## Build and run 🛠️

🛠️ In a Visual Studio Developer Command Prompt, build the source with:

```bat
cl /EHsc "free money holy shit.cpp" /Fe:free-money.exe
free-money.exe
```

Press **Ctrl+C** to stop. The program writes UTF-8 output; emoji appearance depends on the terminal and font. 🖥️

🧪 The checked-in executable is a prebuilt artifact. Build the source to see the emoji changes.

## 🎮 What you see

- 💸 A greeting when the program starts.
- 💰 A pretend-money total printed in the console.
- ⏱️ The total doubles on each iteration, with a one-second delay.
- 🛑 Stop the loop with Ctrl+C.
